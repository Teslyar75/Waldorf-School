## Коротко про проєкт

У «Ступенів» уже є теплий, впізнаваний сайт: цитата Штайнера в шапці, «Ритм року», карусель учителів, тексти про педагогіку. Але як інструмент школи він «застиг»:

- останні новини — **грудень 2023**;
- форма «Напишіть нам» у статичній копії **не надсилає** листи;
- на живому сайті стоїть `noindex, nofollow` — пошуковики його майже не бачать;
- немає офіційного розділу **«Інформаційна відкритість»** за ст. 30 Закону «Про освіту».

Мета проєкту — не просто «перемалювати» вітрину, а зібрати **робочу систему з п’яти модулів**:

1. **Публічний сайт** — той самий дух теми «Waldorf», плюс розділ ст. 30, живі новини, робоча форма з згодою на ПДн, SEO.
2. **Адмінка** — контент, документи, ролі, згоди на фото, заявки (CRM).
3. **Електронний журнал** — вальдорфський шар (характеристики, епохи) поверх державної **«Мрії»**, без подвійного введення.
4. **Агент соцмереж** — чернетки постів за «Ритмом року», публікація лише після схвалення людиною, UTM і ліди.
5. **Оркестратор** — AI-агент, який розкладає задачу директора по модулях і пише в журнал аудиту.

**Три наскрізні правила:** діти — не контент (фото лише зі згодою); одне джерело правди на кожен тип даних; усе через API з тими самими правами, що й у людей.

Повна архітектура — у [`docs/Вальдорфская-школа-схема-автоматизации.md`](docs/Вальдорфская-школа-схема-автоматизации.md) (також [HTML](docs/Вальдорфская-школа-схема-автоматизации.html)).  
Покроковий план — у [`docs/Ступені-план-действий-по-проекту.md`](docs/Ступені-план-действий-по-проекту.md) (також [HTML](docs/Ступені-план-действий-по-проекту.html)).

## Перспективи і план впровадження

Орієнтовний обсяг: **~65–120 людино-днів** (≈ 4–7 місяців при частковій зайнятості одного розробника). Найдовше — не код, а збір документів і рішень школи.

| Фаза | Що дає школі | Пріоритет |
|------|----------------|-----------|
| **0. Основа** | Git, доступи, рішення по стеку, staging | одразу |
| **1. Ст. 30 (quick win)** | «Інформаційна відкритість», робочі форми, свіжі новини, зняття `noindex` | **високий** (закон) |
| **2. Журнал** | пілот «Мрії» + Telegram-бот для батьків | середній |
| **3. Соцмережі** | календар «Ритм року», агент-чернетки, UTM, заявки | середній |
| **4. Адмінка + AI** | одна панель: контент, документи, ролі, ліди; агент з human-in-the-loop | поступово |

**Рекомендований шлях:** спочатку швидко закрити закон на статиці (або в поточному WordPress), паралельно звернутися до «Мрії»; «велику» систему будувати на новому стеку (.NET 8 / PostgreSQL / React або Astro) — див. розділ «Технологічний стек» у схемі автоматизації.

Детальні кроки 0.x–4.x, чек-лист для школи й відкриті питання — у [плані дій](docs/Ступені-план-действий-по-проекту.md).

```mermaid

  D0["0. Основа"] --> S1["1. Ст. 30"]
  D0 --> S2["2. Журнал / Мрія"]
  D0 --> S3["3. Соцмережі"]
  S1 --> S4["4. Адмінка + AI"]
  S2 --> S4
  S3 --> S4
```

## Локальний перегляд сайту

Потрібен [Node.js](https://nodejs.org/).

```bat
start.bat
```

або:

```bash
npx --yes serve -l 5180 .
```

Відкрити: http://127.0.0.1:5180/

> Contact Form 7 і PHP-форми в статичній копії **не працюють** — потрібен бекенд або зовнішній сервіс форм. На скріншотах видно помилку reCAPTCHA для `localhost` — це очікувано.

## Головні прогалини поточного сайту

1. Немає розділу **«Інформаційна відкритість»** (статут, ліцензії, правила прийому, вартість, булінг, форми навчання…).
2. Новини не оновлюються з грудня 2023.
3. Форма не працює без PHP і не запитує згоди на ПДн.
4. **`noindex, nofollow`** — при запуску редизайну зняти, додати sitemap і 301 з дублів URL.
5. Фото дітей без обліку згод — перед індексацією потрібна ревізія медіатеки.
6. «Методичні матеріали» / частина сторінок — заглушки; «Структура школи» дублює тексти головної.

## Технічні нотатки про копію

- Джерело: WordPress, тема **«Waldorf»** (2023), jQuery 3.7, Flickity, Contact Form 7 + reCAPTCHA.
- Каталог з WP REST API: [`catalog.json`](catalog.json) — 17 сторінок, 5 новин, 75 медіа.
- Звіт дзеркала: [`mirror-report.json`](mirror-report.json) — 365 файлів, 30 помилок (переважно артефакти `…/r/`).
- Уже зроблені **візуальні** правки (шапка, мобільне меню, «рвані» рамки, шахові блоки структури, focus на обличчях у банерах). Тексти й новини поки як на живому сайті.
- Папка `_debug-header/` у `.gitignore` — робочі скріншоти «до/після», не для публікації.
