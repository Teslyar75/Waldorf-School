# Что сделать в Украине, чтобы выставить сайт «Ступені» в интернет

Практический чек-лист для директора / учредителя / ответственного за сайт.  
Это не юридическая консультация: по спорным пунктам сверьтесь с юристом школы и актуальным текстом законов.

Связанные документы:

- [Інформаційна відкритість](../Informaciyna-vidkrytist-sajt-Stupeni.md) — перечень по ст. 30  
- [План действий · Поток 1](Ступені-план-действий-по-проекту.md#s1) — шаги внедрения  
- [Как работает «Выпускник недели»](Как-работает-выпускник-недели.md) — рассылка и Telegram  

---

## Коротко: два разных «можно выставить»

| Вопрос | Что нужно |
|--------|-----------|
| **Технически** открыть сайт по адресу в интернете | домен, хостинг (или GitHub Pages / VPS), DNS, публикация файлов |
| **Законно и спокойно** держать сайт школы | раздел «Інформаційна відкритість» (ст. 30), защита персональных данных, актуальные документы, снять `noindex` только когда контент готов |

Сейчас живой сайт уже есть (`waldorf-stupeni.school`), но он «застывший» и частично скрыт от поиска. «Выставить» редизайн = **заменить/обновить** то, что видят родители, и закрыть обязательные требования.

---

## 1. Организационные решения внутри школы

Сделайте это **до** массовой публикации:

1. **Назначить ответственных** (приказ / распоряжение директора):
   - за официальный раздел сайта (ст. 30);
   - за персональные данные и согласия;
   - за новости / соцсети;
   - за доступы (пароли — в менеджере паролей, не в чатах).
2. **Решение педрады / учредителя** (при необходимости): где будет жить новый сайт (обновление текущего WordPress / новый хостинг / статика).
3. **Собрать доступы:**
   - домен и DNS (кто регистратор — часто nic.ua, ukraine.com.ua, Cloudflare и т.п.);
   - текущий хостинг и панель;
   - wp-admin живого сайта (если ещё WordPress);
   - школьная почта;
   - Google-аккаунт школы (для Search Console).

Без доступов к домену/хостингу «выставить» новый вариант на тот же адрес нельзя — только показать демо на другом URL.

## 2. Технически выложить сайт в интернет

### 2.1. Домен

- У школы уже есть домен **waldorf-stupeni.school** — уточните, на кого оформлен (ФОП, ТОВ, физлицо) и до какой даты оплачен.
- Если нужен новый домен (.ua / .com.ua / .school) — регистрация у украинского или международного регистратора; для `.ua` часто нужны документы юрлица / основания (смотрите правила конкретного регистратора).

### 2.2. Хостинг (куда класть файлы)

Варианты для «Ступеней»:

| Вариант | Когда подходит |
|---------|----------------|
| Текущий хостинг WordPress | быстро обновить тему/страницы на том же сервере |
| Статический хостинг (Netlify, Cloudflare Pages, GitHub Pages) | если сайт — статика + отдельный бэкенд CMS |
| VPS в Украине или ЕС (Hetzner, DigitalOcean, украинские провайдеры) | нужен свой Node/Express, админка, бот |

Нужно:

1. Аккаунт хостинга + оплата.  
2. Привязка домена (A / CNAME записи в DNS).  
3. HTTPS (сертификат Let’s Encrypt — обычно бесплатно в панели).  
4. Загрузка сборки сайта (без служебных папок `_debug-header`, без `.env` с секретами).

### 2.3. Когда можно «открыть» для Google

На живом сайте сейчас часто стоит `noindex, nofollow`.  
**Снимать запрет индексации** только когда:

- раздел ст. 30 заполнен или честно помечен «не застосовується»;
- нет устаревших критичных ошибок;
- проверены фото детей (согласия);
- есть `robots.txt` и `sitemap.xml`;
- настроены 301 со старых URL (если менялись адреса).

После запуска: Google Search Console → добавить свойство → отправить sitemap.

## 3. Закон «Про освіту», статья 30 — обязательный блок на сайте

Частный заклад тоже обязан обеспечивать **прозорість та інформаційну відкритість**.  
Ориентир: [Що має бути на сайті школи? (НУШ)](https://nus.org.ua/2025/04/26/shho-maye-buty-na-sajti-shkoly/).

На сайте должен быть удобный раздел (например «Інформаційна відкритість») с документами и страницами, в том числе:

### Документы заведения

- статут;
- ліцензії на освітню діяльність;
- сертифікати акредитації (якщо є).

### Управление и кадры

- структура та органи управління;
- кадровий склад (за ліцензійними умовами);
- вакансії / конкурс (якщо проводиться).

### Освітній процес

- освітні програми / компоненти;
- мова навчання;
- ліцензований обсяг і фактична кількість учнів;
- матеріально-технічне забезпечення;
- результати моніторингу якості;
- річний звіт;
- форми здобуття освіти (які саме пропонує заклад).

### Вступ, вартість, доступність

- правила прийому (школа + садочок);
- умови для дітей з ООП;
- розмір плати / додаткові послуги і порядок оплати.

### Правила и буллинг

- правила поведінки;
- план протидії булінгу;
- порядок подання і розгляду заяв (з конфіденційністю);
- контакти відповідальних.

### Другое по перечню ст. 30 / НУШ

Сверьте полный список в [Informaciyna-vidkrytist-sajt-Stupeni.md](../Informaciyna-vidkrytist-sajt-Stupeni.md).  
Для неприменимых к частной школе пунктов — короткая пометка «не застосовується, тому що …», а не пустая страница.

**Практика:** PDF + дата «Оновлено: …»; ответственный обновляет в срок (часто 10 рабочих дней после утверждения документа).

## 4. Персональные данные (Украина)

При регистрации родителей, формах, фото, Telegram:

1. Закон Украины **«Про захист персональних даних»** — обработка только с основанием (согласие / договор и т.д.).
2. На сайте:
   - политика конфиденциальности / обробка ПДн;
   - галочка согласия в формах (`/batky/`, «Напишіть нам»);
   - контакты ответственного за ПДн.
3. Фото детей — только при наличии согласий родителей; без согласия не публиковать.
4. Telegram — зарубежный сервис: родителей стоит предупредить (это уже заложено в плане журнала).
5. Не выкладывать в открытый доступ паспорта, полные адреса детей, лишние ПДн в PDF.

Отдельная регистрация базы ПДн в госреестре — по ситуации (уточнить у юриста: зависит от объёма и характера обработки). Для школьного сайта минимум — **прозрачные согласия и политика на сайте**.

## 5. Хозяйственные и «бумажные» моменты

| Тема | Что проверить |
|------|----------------|
| Юрлицо / ФОП школы | кто заказчик хостинга и домена, на чьё имя счета |
| Ліцензія МОН | актуальная, PDF на сайте |
| Статут | актуальная редакция |
| Договір з батьками | ссылка на правила сайта / ПДн, если нужно |
| ФОП / бухгалтерия | если платный хостинг — договор и акты |

Отдельного «разрешения МОН на запуск сайта» обычно **нет**: сайт — обязанность прозрачности, а не отдельная лицензия. Нужны **лицензия на образовательную деятельность** и публикация сведений по ст. 30.

## 6. Чек-лист «можно выставлять редизайн»

Отметьте перед заменой продакшена:

### Документы и контент

- [ ] Раздел «Інформаційна відкритість» собран (или этап 1 с пометками)
- [ ] Статут, лицензии, правила прийому, вартість, булінг — доступны
- [ ] Кадровый состав дополнен по требованиям
- [ ] Новости не выглядят «мёртвыми» (хотя бы актуальный блок)
- [ ] Формы работают + согласие на ПДн
- [ ] Политика конфиденциальности опубликована
- [ ] Фото детей проверены на согласия

### Техника

- [ ] Доступы к DNS и хостингу есть
- [ ] HTTPS работает
- [ ] Бэкап старого сайта сделан
- [ ] `noindex` снят **осознанно**
- [ ] `sitemap.xml` + Search Console
- [ ] Секреты (токены бота, Resend) только в env, не в Git

### Коммуникация

- [ ] Родителям объявлено (чат / Telegram), куда смотреть
- [ ] Назначен человек, кто правит документы после запуска

## 7. Минимальный порядок действий «с нуля до открытого сайта»

1. Назначить ответственных и собрать доступы (домен, хостинг, почта).  
2. Собрать пакет документов ст. 30 (папка PDF + тексты).  
3. Подготовить страницы на новом/обновлённом сайте + политику ПДн.  
4. Выложить на staging-URL (поддомен) → проверить с телефона.  
5. Сделать бэкап текущего продакшена.  
6. Переключить домен / залить продакшен.  
7. Снять `noindex`, отправить sitemap в Google.  
8. Сообщить родителям; дальше — рассылка / Telegram / журнал (отдельные этапы).

---

## 8. Чего не ждать от государства

- Отдельного «сертификата на сайт» от МОН обычно нет.  
- «Мрія» / электронный журнал — **другой** поток; сайт по ст. 30 нужен в любом случае.  
- Проверка прозрачности может быть со стороны родителей, управления образования, общественности — поэтому раздел ст. 30 лучше закрыть раньше, чем «дополировать» дизайн.
