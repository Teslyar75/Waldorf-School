# Как работает «Выпускник недели» и рассылка родителям

Документ для школы «Ступені»: что делает система, что видит родитель, что появляется на сайте.

Технические детали API и файлов — в [`alumni-parents-pipeline.md`](alumni-parents-pipeline.md).

---

## Идея простыми словами

1. Родитель **регистрируется** на сайте и соглашается получать письма.
2. Раз в неделю система **сама**:
   - берёт следующего выпускника вальдорфской школы из очереди;
   - публикует на нашем сайте **страницу** с чуть более развёрнутым текстом и ссылкой на оригинал (Wikipedia / сайт человека / theWaldorfs);
   - **шлёт уведомление** подписчикам: короткий текст + ссылка на нашу страницу.
3. Родитель открывает ссылку на телефоне → читает на сайте «Ступеней» → при желании переходит к первоисточнику.

```text
Очередь выпускников
        ↓
  Тижневий цикл (автоматически)
        ↓
   ┌────┴────┐
   ↓         ↓
Страница    Уведомление
на сайте    (письмо / позже Telegram)
/vypusknyky/...   со ссылкой на сайт
```

## Что получает родитель

### Уведомление (короткое)

- Заголовок вроде: «Випускник тижня: …»
- 1–2 предложения, кто это и чем известен
- **Ссылка на страницу нашего сайта**
- Ссылка «отписаться»

Каналы уведомлений:

| Канал | Статус | Как доходит на телефон |
|-------|--------|-------------------------|
| **Email** | каркас есть (stub / Resend) | письмо в почтовом приложении |
| **Telegram-бот** | в плане (см. ниже) | сообщение в Telegram со ссылкой |
| SMS / push | не делаем пока | — |

### Страница на сайте (чуть подробнее)

Адрес вида: `/vypusknyky/<slug>/`

На странице:

- имя выпускника;
- короткое описание украинским текстом (наш пересказ, не копипаст чужой биографии);
- профессия / страна;
- **ссылка на материалы**: Wikipedia, личный сайт или страница о человеке (как в каталоге theWaldorfs — поле WWW);
- пометка об источнике каталога (theWaldorfs) и авторских правах.

Список всех таких публикаций: `/vypusknyky/`.

---

## Регистрация родителей

Страница: `/batky/`

Родитель указывает email, имя, класс ребёнка и согласия.

1. Статус `pending` — ждёт подтверждения email.  
2. Переходит по ссылке из письма → статус `active`.  
3. Только `active` получают «Выпускника недели» и (позже) уведомления о событиях школы.

Отписка — ссылка в каждом письме.

## Откуда берутся выпускники

| Источник | Как |
|----------|-----|
| Демо-очередь | `npm run alumni:seed` — несколько известных имён для проверки |
| Каталог theWaldorfs | импорт (каркас: `npm run alumni:import-dry`) — имена + ссылки WWW |
| Вручную | админ API / позже UI в админке |

Система **не копирует** длинные биографии с чужих сайтов. На нашей странице — краткий свой текст + ссылка «узнать больше» на оригинал.

---

## Что происходит раз в неделю (автомат)

Команда: `npm run alumni:weekly`  
(на сервере — по расписанию: Task Scheduler / cron / GitHub Actions)

1. Берёт первого выпускника со статусом `queued`.  
2. Собирает HTML-страницу и кладёт в `vypusknyky/<slug>/`.  
3. Записывает метаданные в `alumni-articles.json`.  
4. Помечает выпускника как `published`.  
5. Рассылает всем активным родителям письмо со ссылкой на эту страницу.

Пока нет ключа почтового сервиса, письма пишутся в журнал `data/mail-log.json` (удобно для разработки, на телефон не приходят).

## Роли «сайт» vs «уведомление»

| | Уведомление | Страница на сайте |
|--|-------------|-------------------|
| Длина | коротко | чуть развёрнутее |
| Цель | «открой ссылку» | почитать и перейти к источнику |
| Ссылки | на наш сайт | на Wikipedia / сайт человека / theWaldorfs |

## Что уже есть / чего ещё нет

**Есть (каркас работает локально):**

- форма регистрации `/batky/`;
- очередь выпускников и публикация статей;
- рассылка email (stub или Resend);
- документация и npm-скрипты.

**Ещё предстоит:**

- постоянный хостинг сайта в интернете (чтобы ссылка открывалась не только с вашего ПК);
- боевая почта (Resend) и/или **Telegram-бот** (см. раздел ниже);
- автозапуск раз в неделю на сервере;
- уведомления о событиях из календаря школы;
- удобный экран в админке.

## Что сделать вам дальше (чек-лист)

Цель: **первое уведомление на телефон** со ссылкой на наш сайт, а на сайте — страница с чуть более развёрнутым текстом и ссылкой на Wikipedia / сайт человека / theWaldorfs.

### A. Пока сайт только на вашем компьютере (`localhost`)

Так можно проверить механизм, но **с телефона страница не откроется**.

1. В папке проекта:
   ```bash
   npm start
   npm run alumni:seed
   npm run alumni:weekly
   ```
2. Открыть на ПК: http://127.0.0.1:5180/vypusknyky/  
3. Письма смотреть в `data/mail-log.json` (на телефон не приходят без Resend/Telegram).

### B. Первое уведомление на телефон через email

1. **Выложить сайт** в интернет (ваш домен или staging), чтобы с телефона открывался URL статьи.  
2. Запомнить публичный адрес, например `https://www.waldorf-stupeni.school`.  
3. **Подключить Resend** ([resend.com](https://resend.com)):
   - создать API-ключ;
   - перед запуском задать переменные окружения:
     ```text
     MAIL_PROVIDER=resend
     RESEND_API_KEY=re_...
     MAIL_FROM=Ступені <ваш@домен>
     SITE_URL=https://ваш-публичный-адрес
     ```
   - для теста можно временный отправитель Resend `onboarding@resend.dev` (письма только на ваш же email).  
4. Зарегистрироваться **своим email** на `/batky/` (тот же ящик, что на телефоне).  
5. **Подтвердить email** по ссылке из письма.  
6. Запустить:
   ```bash
   npm run alumni:seed
   npm run alumni:weekly
   ```
7. На телефоне открыть письмо → ссылка на `/vypusknyky/...` → на странице развёрнутый текст и ссылка на оригинал.

### C. Telegram-бот — как это у нас и что для этого нужно

**Статус:** пока в плане (код подключим, когда будут токен и публичный сайт). Ниже — именно наш сценарий для «Ступенів».

#### Зачем бот в нашем случае

Родителям удобнее получать короткое сообщение в Telegram на телефон, чем искать письмо. Бот школы:

1. раз в неделю пишет: «Випускник тижня: …» + **ссылка на страницу нашего сайта**;
2. позже тем же ботом можно слать объявления / ссылки из **электронного журнала** (требование МОН — отдельный этап);
3. на сайте родитель читает чуть более полный текст и переходит к Wikipedia / сайту человека / theWaldorfs.

```text
Родитель  →  /start у бота «Ступені»
                    ↓
            chat_id в списке подписчиков
                    ↓
Раз в неделю job  →  статья на сайте /vypusknyky/...
                    ↓
            сообщение в Telegram всем подписчикам
                    ↓
Родитель на телефоне открывает ссылку → страница школы
```

#### Как это работает для родителя (по шагам)

1. В Telegram находит бота школы (ссылка с сайта `/batky/` или из чата класса).  
2. Нажимает **Start** / пишет `/start`.  
3. Бот отвечает приветствием и сохраняет его как подписчика.  
4. Раз в неделю приходит сообщение примерно такого вида:
   - «Випускник тижня: Jennifer Aniston»
   - 1–2 предложения, кто это
   - кнопка/ссылка: открыть на сайте «Ступені»
5. По ссылке открывается наша страница с развёрнутым текстом и ссылкой на оригинал.  
6. Чтобы отписаться — `/stop` (или кнопка «Відписатися»).

Опционально: на `/batky/` кнопка «Підписатися в Telegram» (deep-link), чтобы не искать бота вручную.

#### Что видит родитель в боте vs на сайте

| | В Telegram | На сайте `/vypusknyky/...` |
|--|------------|----------------------------|
| Объём | коротко | чуть подробнее |
| Ссылки | на наш сайт | на Wikipedia / сайт персонажа / theWaldorfs |
| Цель | «посмотри» | «прочитай и углубись» |

#### Что нужно от вас (школа / вы лично), чтобы запустить

| № | Что сделать | Зачем |
|---|-------------|--------|
| 1 | Создать бота в [@BotFather](https://t.me/BotFather): `/newbot` | без бота Telegram некому писать |
| 2 | Имя, напр. `Ступені · для батьків` | как видно в списке чатов |
| 3 | Username, напр. `stupeni_parents_bot` | постоянная ссылка `t.me/...` |
| 4 | Скопировать **токен** (`123456:AA...`) | доступ сервера к API Telegram |
| 5 | **Не** публиковать токен в Git / чатах | безопасность |
| 6 | Передать токен разработчику или положить в env `TELEGRAM_BOT_TOKEN` | подключение кода |
| 7 | Иметь **публичный URL сайта** (`SITE_URL`) | ссылки в сообщениях должны открываться с телефона |
| 8 | (Желательно) решить, кто админ бота в школе | кому писать, если бот «молчит» |

Пример env после настройки:

```text
TELEGRAM_BOT_TOKEN=123456:AA...ваш_токен...
SITE_URL=https://www.waldorf-stupeni.school
```

#### Что делает разработчик (после того как вы дали токен и URL)

1. Код бота: команды `/start`, `/stop`, сохранение `chat_id`.  
2. Связка с `alumni:weekly`: после публикации статьи — рассылка в Telegram.  
3. Кнопка подписки на `/batky/`.  
4. Позже — те же сообщения/ссылки в контур **электронного журнала**.

#### Чего пока не нужно

- отдельный SMS-шлюз;
- свой сервер Telegram;
- обязательный email для тех, кто подписался только в боте (email можно оставить параллельно).

**Итого для старта бота вам сейчас достаточно:** создать бота в BotFather → прислать токен → сказать публичный адрес сайта. Остальное — в коде.

## Связь с электронным журналом (позже)

**Новое требование МОН:** у школы должен быть электронный журнал / учёт (официальный контур — в частности «Мрія», плюс свой слой для родителей). Это **отдельный большой поток** проекта — см. [План действий · Поток 2. Электронный журнал](Ступені-план-действий-по-проекту.md#s2) и схему автоматизации (модуль журнала + «Мрія»).

Сейчас рубрику «Выпускник недели» делаем **отдельно**, но с расчётом на стыковку:

| Что уже закладываем | Как потом войдёт в журнал |
|---------------------|---------------------------|
| Telegram-бот | тот же бот (или его каналы) станет входом для родителей к объявлениям / ссылкам из журнала |
| Ссылки на статьи `/vypusknyky/...` | будут попадать и в ленту/уведомления журнала (не только в рассылку сайта) |
| Регистрация родителей `/batky/` | позже — единый профиль родителя: подписка, согласие на ПДн, привязка к классу ребёнка |
| События школы | календарь + журнал + бот — одни и те же уведомления, без дублирования вручную |

**Правило на будущее:** одно событие / одна статья → одна запись в «ленте» → рассылка в Telegram (и при необходимости email) + отображение в электронном журнале / кабинете родителя.  
Сайт остаётся местом **развёрнутого текста**; журнал и бот несут **короткое уведомление + ссылку**.

По журналу вернёмся отдельно (после каркаса сайта и первой рассылки). Пока код журнала не трогаем.
